Match-level tape is parsed from [Cricsheet](https://cricsheet.org/) IPL male CSV2
(`ipl_male_csv2.zip`, info files only). Ball-by-ball files are not stored here.

Rebuild:

```bash
python scripts/build_matches.py --zip /path/to/ipl_male_csv2.zip
```

Cricsheet terms: attribution required; data is provided for public use.
Seasons in this snapshot: 2007/08 through 2026.
